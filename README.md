# Reset Life Blogs

A full-stack blog application built using the MERN stack as part of my Codomax internship.

## Features

- User registration and login
- JWT-based authentication
- Create blog posts
- Upload blog images
- View blogs
- Edit blogs
- Delete blogs
- User dashboard
- User profile
- Category selection
- Responsive UI

## Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- Multer
